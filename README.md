# Geospatial Product Evidence (GPE)

Production vocabulary repository for the IJGI reconstruction project.

**Canonical namespace:** `https://maple-feng.github.io/gpe/#`

Version 1.0 resources:

- `index.html` — HTML vocabulary landing page
- `gpe.ttl` — RDF/Turtle vocabulary
- `context.jsonld` — JSON-LD 1.1 context
- `v1.0/` — version 1.0 snapshot (completed during FG-04 closure)

The vocabulary is standards-aligned and uses PROV-O/DCAT/RDF concepts where appropriate. It does **not** claim ISO conformance.

The development namespace `https://example.org/gpe#` is superseded only after FG-04 production-namespace regeneration and regression are formally closed.
